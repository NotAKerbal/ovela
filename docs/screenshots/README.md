# README screenshots

These are browser captures of the running Ovela application, taken on September 4, 2026. They use the existing self-hosted installation and its application catalog. They are not design mockups.

| File | View | Capture size |
| --- | --- | --- |
| `home.png` | Home, all four application tiles | 1440 × 1000 |
| `applications.png` | Manage → Applications | 1265 × 834 |
| `home-mobile.png` | Home at a phone breakpoint | 390 × 844 |

To refresh them:

1. Start Ovela and sign in as an administrator.
2. Open the home page and wait for the tiles, fonts, and profile image to finish loading and animating.
3. Capture the desktop and mobile views at the sizes above. Check the saved files, since a capture taken during a resize or transition can miss the tiles.
4. Open Manage, select Applications, and capture the complete catalog.
5. Check each image for personal contact details, tokens, private hostnames, or other information unsuitable for the public repository. Avoid the People and Account screens when they contain personal email addresses.
6. Replace the files here and check the root README's image links and gallery layout.

The current images show Photos connected to local Immich. Files, Media, and Notes are not connected. Keep screenshots and captions consistent with the actual installation rather than filling in invented application data.
